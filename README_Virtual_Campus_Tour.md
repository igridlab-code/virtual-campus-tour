# Virtual Campus Tour

### An Interactive 360° Virtual Campus Exploration Project

**Platform:** Panoee  
**Image Capture:** iPhone Panorama (PANO) Mode  
**Access:** Web Browser and VR Mode

## 1. Introduction

The Virtual Campus Tour is an interactive 360° virtual tour created using the Panoee platform. It allows students, parents, visitors, and guests to explore the college campus digitally without physically visiting every location. Users can move between campus locations through interactive hotspots. Each location can display its name and relevant images to help users understand the campus environment. The tour is accessible through a web browser and supports Fullscreen and VR viewing modes.

## 2. Objective

The main objective of this project is to provide students, parents, visitors, and guests with an easy and interactive way to explore the college campus virtually.

- Provide a digital representation of the college campus.
- Enable remote exploration of different campus locations.
- Improve the campus visiting experience through 360° panoramic images.
- Make the virtual tour accessible through an online link.

## 3. Key Features

- Interactive 360° campus view
- Hotspot-based navigation
- Location names displayed on hotspots
- Navigation between different campus locations
- Additional images for locations
- Fullscreen viewing
- VR mode support
- Browser-based access
- Shareable virtual tour

## 4. Platform and Tools Used

- **Panoee** – used to create and organize the interactive virtual tour.
- **iPhone Panorama (PANO) Mode** – used to capture panoramic campus images.
- **Web Browser** – used to access and explore the virtual tour.
- **VR Mode** – used to provide an immersive virtual viewing experience.

## 5. 360° Image Capture

The panoramic images used in this project were captured using an iPhone with its built-in Panorama (PANO) mode. The captured images were uploaded to the Panoee platform and arranged as individual virtual tour locations to create an interactive campus exploration experience.

## 6. Project Workflow

1. Capture panoramic images of different campus locations using an iPhone.
2. Upload the panoramic images to the Panoee platform.
3. Create individual virtual tour locations.
4. Add interactive hotspots to each location.
5. Connect hotspots to other campus locations.
6. Add location names and additional images.
7. Configure the virtual navigation.
8. Enable Fullscreen and VR viewing options.
9. Publish the completed Virtual Campus Tour.
10. Share the tour through its online link.

This project was developed for educational and demonstration purposes. It showcases the use of 360° panoramic photography and virtual-tour technology for campus exploration.

## 13. Conclusion

The Virtual Campus Tour demonstrates how 360° panoramic photography and the Panoee platform can be used to create an interactive digital campus experience. Through hotspot-based navigation, Fullscreen viewing, and VR support, users can explore different campus locations from anywhere. The project also provides opportunities for future development through interactive maps, AI assistance, and enhanced VR features.
